# I Am Taxi Driver

I Am Taxi Driver is a browser taxi parking challenge about calm steering, clean turns, and careful timing. The page describes the browser version plainly and avoids official-app claims, guaranteed rewards, and pressure to install software.

## Game Embed

- Local route: `/game/index.html`
- External embed: https://html5.gamemonetize.co/dtpq5tr2quj6qxmfsp1ipdfi82n2o06h/
- Source: GameMonetize - Taxi Parking Challenge 2

## Copy Direction

Keep the page useful, human, and suitable for a general audience. Focus on how the browser game works, how to play safely, and how players can improve through practice.

## Core Play Advice

Slow down before corners, line up the taxi early, and treat each parking bay like a precision puzzle.
